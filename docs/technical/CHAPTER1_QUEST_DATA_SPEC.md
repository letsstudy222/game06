## Activation/evidence/commit

Existing quest acceptance/step lựa chọn nếu cần có một owner; source facts/event completions/memory/journal giữ riêng đúng domain, projection tính sau source revision. Prior eligible proof được query khi quest available/active/load, không bắt signal phải phát lại. Missing predecessor/source eligibility vẫn chặn commit, không credit hành động chưa từng hợp lệ hoặc UI disabled auto complete.

Action/source validate→candidate proof/outcome + physical/world patches + quest evidence + reward payload/recipients + route/checkpoint/habitat→W07 atomic-equivalent durable commit→projection/UI/dialogue. Concurrent requests dùng sequence/expected revision, conflicts revalidate, no last callback wins. Source claimed trả frozen result, same source different payload diagnose; content version không new claim. Notification/camera/animation chỉ presentation.

## State và recovery

Năm recommended derived statuses và three overlays ở [quest state model](../chapter1/CHAPTER1_QUEST_WORLD_STATES.md), không save enum song song event. E01 form_committed trước parent practice, E04 outcome trước E05 restoration, E05 available-I trước E06 arrival-return là boundaries không được gộp. Boss lock membership khác allowed switch; HP0/cost/retry policies unresolved không được schema tự default.

Load integrity/reference/owner/receipt validation, last-good recovery, rebuild projection/cache không replay grant. Durable form nhưng missing UI alias: resume practice, không derive parent complete. Missing true authority cần quarantine/approved recovery, không tự completion/heal/clear status để làm save đẹp. Unknown species/unapproved source art/zone/required localization không activate production-ready; retained opaque refs/proofs không xóa.

Migration quest/objective/event/habitat/zone/animation refs dùng explicit maps, preserve canonical source claims/recipients/outcomes và backup. Quest display rename không migration logical reward; optional future scope/route không reset ChapterI hoặc thêm hidden main collection deficit. Future shared event nhiều quest consumer đọc cùng proof; extra reward chỉ khi author distinct source component/budget, không mỗi consumer grant lại. Không backend/loader/runtime code/production JSON được chọn/viết trong Task21.
