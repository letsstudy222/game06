# Combat QA scenarios — tương lai

**PROPOSED C14-P16**. 32 scenarios dưới là acceptance design, **chưa chạy runtime tests**. Outcomes conditional trên proposals được duyệt; C14-U gates phải chốt trước fixtures executable. Không dùng tests Phoenix cũ làm evidence cho hệ mới. [Data contracts](COMBAT_DATA_SPEC.md), [decisions](../combat/TASK14_DECISIONS.md).

Mỗi case cần fixture catalog/profile/geometry/clock/ledger version đúng. Kiểm deterministic sequence ở nhiều frame pacing; rendering không authority. Report pass/fail/skip/unrun riêng khi thực thi về sau.

## QA release gate

Test subset chỉ hợp lệ khi approved rules/values/assets/modules và loss/reload policy đủ rõ. Unit/state/property tests cho ledgers/interrupt/ordering; integration cho form/status/encounter/save; browser keyboard/touch/focus/telegraph playback; hardware/mobile/performance và playtest balance là evidence riêng. Không một zero-test/syntax-only run chứng minh combat feel. Task14 chỉ kiểm completeness/links/status/document consistency.
