## Validation and schema gates

All refs resolve/types unique; candidate BossDefinition binding không replace S05 profile/actor/event identity. Exact HP/mitigation/control/resource/timing/phase thresholds/placement/entry/retry/qualifying trial predicates chưa approved phải gapRef và content not-ready, không loader tự default. Health/action/hit/status/lock/quest/progression/reward/world state mỗi property một owner, phase/AI/UI không shadow stores.

Source event/quest mappings E03→E04→E05→E06 unchanged, no optional/three forms/stageII or dual gates. Entity definitions data-driven reusable modules, not boss-specific procedural engine. Shape/marker geometry same coordinate/layer as motion/collision, camera render offset no reach change. No main reaction immunity or basic zero-damage profile allowed under intended QuyI route.

## Save, migration and interruption

Durable E04 outcome+actor/quest/required world patches+ledger/all recipients+safe placement/route check atomic before publish, no death animation/grant callback. Attempts/casts/phase/projectiles/current fields transient under selected L16 policy; recommended active reload abort/reset, completed E04 restores result not replay. Source/world E03 baseline retained after failed attempt. Required accepted harmful obligations per E09/C14/W07 don't vanish merely due cull/reset/load unless approved recovery says so.

Boss/attack/phase/animation/anchor aliases/version changes keep actor/event/canonical grant identity, earned progression and original source payload. Unknown newer config/obsolete phase/invalid checkpoint preserve backup/last-good and reconcile/reset by approved policy; no downgrade/state fabrication/free heal. Source identity/version metadata separate; same source different payload conflict diagnose, no recipient switch/retry alternative branch extra claim. Storage/health/outcome arbitration policies still unresolved, no code/classes/JSON/production loader implemented.
