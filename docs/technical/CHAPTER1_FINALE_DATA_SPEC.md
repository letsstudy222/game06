## Ownership và boundaries

A E04 durable, B permission+close+safe context, C E05 restoration và D E05 chapter view, R available-I sau E05, N arrived/return E06. C/D không identical meanings nhưng inherited same source write-set/durable boundary; no fake separate CHAPTER_COMPLETED store hoặc movie gate. Optional echo S22/memory/final dialogue/evolution/Phượng form không required core predicate. Exact RuleRefs/source object instances/coverage scope/body/HP/lock/receipt/schema policies still approval gates.

Commands serialize expected relevant-property revision/source versions; atomic candidate gồm proof/outcome+owned mutations+required placement/routes/habitat+all recipients/ledger trước publish. UI/animation/FX/camera/phase caches read-only; partial local accepted setting không complete E05, crossed warm cue không arrivedE06. No all-scene/particle/AI-frame snapshots hoặc gameplay source facts trong settings namespace.

Load integrity/refs/expected source-version write-set/ledger dependency closure before control. Cached chapter flag thiếu thì rederive từ E05 valid; source record/predecessor thật thiếu/mâu thuẫn cần last-good/backup/quarantine/approved migration, no mint event/grant. Optional asset unavailable giữ earned memory/facts và physical cue fallback; actual authoritative records missing không xử bằng cosmetic fallback.

Source/canonical grant identities distinct content/schema/payload/clip/zone names, recipient keys components of same source receipt. Migration backup→alias/outcome mapping→validation→promote, no downgrade/new version free reward. New post-restoration ecology content cần coverage/nav validation với scope/version rõ, không invalidate earned historical E05 hoặc hidden main collectible deficit. Travel held at source if content/return/write invalid, no duplicate controlled player/equip/heal/progression loss. Full engine/save/loader implementation not performed at Task24.
