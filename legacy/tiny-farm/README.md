# Lưu trữ phiên bản nông trại

Đây là nguồn của Tiny Farm trước khi chuyển hướng sang prototype đảo. Các file này không được nạp hoặc xuất bản bởi game hiện tại. Bản nông trại đầy đủ còn trong lịch sử Git tại commit `41cdc6b`.

Giữ lại mã để tham khảo; các bài kiểm thử UI ở đây thuộc phiên bản cũ, không phải suite của game đảo. Các atlas/nền cũ dưới thư mục assets gốc được giữ lại nhưng chỉ asset Nhật Diệm và font được đóng gói cho game đảo. Không xóa hay chuyển đổi localStorage `nhat-diem.farm.v1` của người chơi.
